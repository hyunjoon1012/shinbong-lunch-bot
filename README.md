# 🍚 신봉고 급식 알리미

카카오톡에서 **"오늘 급식"** 이라고 입력하면 신봉고등학교 급식을 알려주는 챗봇입니다.

```
사용자:
오늘 급식

급식 알리미:
🍚 8월 27일 신봉고 급식

현미밥
김치찌개
치킨까스
계란말이
깍두기

735 Kcal
```

네 명이 각자 한 부분씩 만들고, 마지막에 하나로 연결합니다.

## 1. 준비하기

### (1) 프로그램 설치 확인

두 가지가 필요합니다.

| 프로그램 | 확인 방법 | 없으면 |
|---|---|---|
| Python | `python --version` | https://www.python.org/downloads |
| VS Code | 실행해보기 | https://code.visualstudio.com |

> 💡 Mac에서 `python` 이 안 되면 `python3` 을 쓰세요.
> 이 문서의 모든 `python` 을 `python3` 으로 바꿔 읽으면 됩니다.

### (2) 프로젝트 내려받기

처음 한 번만 합니다.

```
1. 브라우저에서 아래 주소를 엽니다

   https://github.com/hyunjoon1012/shinbong-lunch-bot

2. 초록색  < > Code  버튼을 누릅니다

3. 맨 아래 Download ZIP 을 누릅니다

4. 받은 파일의 압축을 풉니다
```

압축을 풀면 폴더 이름이 **`shinbong-lunch-bot-main`** 으로 되어 있습니다.
`shinbong-lunch-bot` 으로 바꾸면 보기 좋습니다. (안 바꿔도 잘 동작합니다)

> ⚠️ **폴더 안에 같은 이름 폴더가 또 있는지 확인하세요.**
>
> ```
> ❌ 잘못 풀린 경우              ✅ 올바른 경우
>
> shinbong-lunch-bot-main/      shinbong-lunch-bot/
> └── shinbong-lunch-bot-main/  ├── app.py
>     ├── app.py                ├── check_setup.py
>     ├── check_setup.py        └── lunchbot/
>     └── lunchbot/
> ```
>
> 왼쪽처럼 되어 있으면 **안쪽 폴더**를 꺼내서 사용하세요.

### (3) VS Code에서 폴더 열기

```
File → Open Folder → 압축을 푼 폴더 선택
```

왼쪽에 `app.py`, `lunchbot` 이 바로 보여야 합니다.

### (4) 터미널 열기

```
Terminal → New Terminal
```

아래 명령들은 모두 이 터미널에 입력합니다.

### (5) 가상환경 만들기

가상환경은 **이 프로젝트에서만 쓰는 파이썬 공간**입니다.
처음 한 번만 만들면 됩니다.

**Windows**

```bash
python -m venv .venv
.venv\Scripts\activate
```

만약 `.venv\Scripts\activate` 실행시 Permission 에러가 난다면 아래 명령을 실행하고 다시 시도

```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Mac / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

성공하면 터미널 맨 앞에 `(.venv)` 가 붙습니다.

> ⚠️ VS Code를 껐다 켜면 다시 `activate` 를 해야 합니다.

### (6) 패키지 설치

```bash
pip install -r requirements.txt
```

## 3. 내가 맡은 파일

네 명이 상의해서 역할을 정하세요.
코딩을 조금 해본 사람은 A와 D, 처음 시작하는 사람은 B와 C를 추천합니다.

| 담당 | 하는 일 | 내 파일 | 실행 명령 |
|---|---|---|---|
| **A** | NEIS에서 급식 데이터 가져오기 | `lunchbot/neis.py` | `python -m lunchbot.neis` |
| **B** | 급식 데이터를 읽기 좋은 메시지로 | `lunchbot/formatter.py` | `python -m lunchbot.formatter` |
| **C** | 카카오톡 질문 이해 + 답장 형식 | `lunchbot/kakao.py` | `python -m lunchbot.kakao` |
| **D** | 웹 서버 만들고 전체 연결 + 파일 합치기 | `app.py`, `lunchbot/service.py` | `python app.py` |

### 서로 기다리지 않습니다

> A가 아직 안 끝났으니 B가 기다린다 ❌
> 네 명이 **동시에** 각자 만든다 ✅

각 파일 안에 연습용 데이터가 들어 있어서, 다른 사람 코드가 없어도 혼자 만들 수 있습니다.
(B와 C는 인터넷도 필요 없습니다.)

## 4. 코드 쓰고 확인하기

### (1) 내 파일을 연다

VS Code 왼쪽에서 위 표의 파일을 클릭합니다.

> 💡 파일에 주석이 아주 많아 보이지만 겁먹지 마세요.
> 대부분 **설명**이고, 실제로 채울 곳은 `# TODO` 라고 쓰인 **한 군데**뿐입니다.

### (2) 실행해본다

```bash
python -m lunchbot.neis     # ← 자기 담당 명령으로 바꿔서
```

처음에는 이렇게 나옵니다.

```
⏳ 아직 구현하지 않았습니다. 위의 TODO 부분을 채워주세요.
   (지금 이 메시지가 나오는 것은 정상입니다)
```

**이건 오류가 아닙니다. 정상입니다.**

### (3) TODO 부분을 채우고 다시 실행한다

```
=== 1. 급식이 있는 날 ===
  ✅ dict 를 돌려준다
  ✅ date 키가 있다
  ❌ menu 키가 있고 list 다
```

**✅ 가 전부 나올 때까지** 고치고 다시 실행합니다.

```
코드 쓰기 → 실행 → ❌ 있으면 고치기 → 다시 실행 → ✅ 전부!
```

이 반복이 이번 프로젝트에서 가장 많이 하게 될 일입니다.

## 5. AI에게 도움받는 법

AI를 써도 됩니다. 다만 **"전부 만들어줘"** 라고 하지 않습니다.

### ChatGPT 같은 채팅 AI를 쓰는 경우

**딱 3단계입니다.**

```
1️⃣  내 파일을 열고 전체 선택 → 복사
     Windows : Ctrl + A  →  Ctrl + C
     Mac     : Cmd + A   →  Cmd + C

2️⃣  ChatGPT 채팅창에 붙여넣기

3️⃣  파일 맨 위 주석에 있는
    "복사해서 쓰는 질문" 을 그대로 이어서 보내기
```

파일 맨 위에 이런 상자가 있습니다. 그 안의 내용을 그대로 쓰면 됩니다.

```
┌──── 복사해서 쓰는 질문 ────────────────────────┐
│ 이건 고등학교 1학년 파이썬 프로젝트 파일이야.  │
│ 파일 아래쪽 테스트를 통과하도록                │
│ get_meal 함수의 TODO 부분만 채워줘.            │
│ ...                                            │
└────────────────────────────────────────────────┘
```

파일 하나만 붙여넣어도 AI가 필요한 정보를 모두 볼 수 있게 만들어 두었습니다.
(API 사용법, 예시 데이터, 통과해야 할 테스트가 전부 파일 안에 들어 있습니다.)

### 조심할 것

| ❌ 이렇게 하지 마세요 | ✅ 이렇게 하세요 |
|---|---|
| AI가 준 파일 전체를 그대로 덮어쓰기 | TODO 자리에만 붙여넣기 |
| 설명을 안 읽고 복사만 하기 | 왜 그렇게 썼는지 설명을 먼저 읽기 |
| 테스트 코드를 고쳐서 통과시키기 | 테스트는 그대로 두고 함수를 고치기 |
| "급식 챗봇 전체를 만들어줘" | "이 for문이 무슨 역할인지 설명해줘" |

### 좋은 질문 예시

```
이 코드에서 for문이 어떤 역할을 하는지 설명해줘.

이 오류가 발생하는 이유를 Python 초보자에게 설명해줘.

이 함수에서 급식이 없는 경우만 처리하고 싶은데
어디를 수정하면 되는지 알려줘.

이 코드가 어떻게 동작하는지 한 줄씩 설명해줘.
```

### 기억할 것 하나

> **내 코드에 들어간 내용은 내가 설명할 수 있어야 한다.**

발표 때 이런 질문을 받습니다.

- 이 함수에는 무엇이 들어오나요?
- 함수 안에서 무엇을 하나요?
- 결과로 무엇이 나오나요?
- 이 `if` 문은 어떤 역할을 하나요?

## 6. 파일 주고받기

각자 자기 파일을 만들고, **카카오톡으로 파일을 주고받아** 하나로 합칩니다.

### 왜 이렇게 해도 괜찮을까?

파일 하나를 담당하는 사람이 **한 명뿐**이기 때문입니다.

```
neis.py       →  A 만 고친다
formatter.py  →  B 만 고친다
kakao.py      →  C 만 고친다
app.py        →  D 만 고친다
service.py    →  D 만 고친다
```

한 파일을 두 사람이 동시에 고치는 일이 없습니다.
그래서 파일을 통째로 주고받아도 서로의 코드가 섞이거나 사라지지 않습니다.

---

### 전체 그림

```
   A ─┐
   B ─┤  카톡으로 자기 파일 보내기
   C ─┘         │
                ▼
          Student D
       (모든 파일을 모아두는 사람)
                │
                ▼
        합쳐서 실행해보기
                │
                ▼
        GitHub 에 올리기 (3주차)
```

---

### A · B · C — 내 파일 보내기

```
① 내 파일을 실행해서 ✅ 가 전부 나오는지 확인한다

② 그 파일 하나만 단톡방에 올린다
   (파일 이름은 절대 바꾸지 않는다)

③ 메시지도 같이 적는다
```

메시지 예시

```
A / neis.py / 8월 25일 / 급식 가져오기 완성
B / formatter.py / 8월 26일 / 급식 없는 날 처리 추가
C / kakao.py / 8월 26일 / 내일 급식 명령 추가
```

> 💡 **PC 카카오톡**을 쓰면 파일을 끌어다 놓기만 하면 되어 훨씬 편합니다.
> 휴대폰만 있다면 메일이나 구글 드라이브로 보내도 됩니다.

내가 무엇을 했는지 짧게 적는 습관을 들이세요.
나중에 **각자 어떤 일을 했는지 보여주는 기록**이 됩니다.

```
✅ 좋은 예                        ❌ 나쁜 예

급식 가져오기 완성                 다했어요
급식 없는 날 처리 추가             수정
내일 급식 명령 추가                ㅇㅇ
카카오 응답 형식 만들기            최종
```

---

### D — 파일 받아서 합치기

Student D는 **모든 파일이 모이는 폴더**(마스터 폴더)를 관리합니다.

```
① 합치기 전에 지금 폴더를 통째로 복사해 둔다
      shinbong-lunch-bot  →  shinbong-lunch-bot-0825
      (날짜를 붙여두면 잘못돼도 되돌릴 수 있다)

② 카톡에서 받은 파일을 다운로드한다

③ 같은 이름의 파일에 덮어쓴다

      받은 neis.py       →  shinbong-lunch-bot/lunchbot/neis.py
      받은 formatter.py  →  shinbong-lunch-bot/lunchbot/formatter.py
      받은 kakao.py      →  shinbong-lunch-bot/lunchbot/kakao.py

④ 잘 합쳐졌는지 실행해서 확인한다

      python -m lunchbot.service

⑤ 단톡방에 "받았어요" 라고 답한다
```

---

### 절대 규칙 3가지

```
1. 내 담당 파일을 남이 보낸 파일로 덮어쓰지 않는다   ← 가장 중요

2. 남의 담당 파일을 고치지 않는다

3. 파일 이름을 바꾸지 않는다
   (neis(1).py 로 저장되었다면 neis.py 로 이름을 되돌린다)
```

---

### 1~2주차에는 남의 파일을 받을 필요가 없습니다

각 파일 안에 **연습용 데이터**가 들어 있어서, 다른 사람 코드 없이도 자기 것을 완성할 수 있습니다.

```
1주차    각자 자기 파일 만들기        →  주고받을 것 없음
2주차    각자 자기 파일 완성하기      →  다 되면 한 번 보내기
3주차    D가 전부 합치고 연결하기     →  이때 다 같이 모임
```

**서로 기다리지 않는 것**이 이 프로젝트의 규칙입니다.

4. 아래쪽 칸에 무엇을 했는지 한 줄 적는다

5. Commit changes 버튼을 누른다
```

여기에 적는 한 줄이 **"우리가 무엇을 만들었는지"** 를 보여주는 기록으로 남습니다.

## 7. 문제가 생겼을 때

### `python` 명령을 찾을 수 없다고 나와요

Mac이라면 `python3` 을 쓰세요.
Windows인데도 안 되면 Python 설치할 때 **"Add Python to PATH"** 를 체크했는지 확인하세요.

### `ModuleNotFoundError: No module named 'flask'`

가상환경을 켜지 않았거나 패키지를 설치하지 않았습니다.

```bash
# Windows
.venv\Scripts\activate
# Mac
source .venv/bin/activate

pip install -r requirements.txt
```

### 터미널 앞에 `(.venv)` 가 안 보여요

가상환경이 꺼져 있습니다. 위 명령으로 다시 켜세요.

### 실행했더니 `⏳ 아직 구현하지 않았습니다` 가 나와요

정상입니다. 아직 TODO를 채우지 않은 것뿐입니다.

### 빨간 글씨가 잔뜩 나왔어요 (Traceback)

당황하지 말고 **맨 아래 줄**을 읽으세요. 거기에 이유가 적혀 있습니다.
그 줄을 그대로 복사해서 AI에게 물어보세요.

```
이 오류가 발생하는 이유를 Python 초보자에게 설명해줘.
(오류 메시지 붙여넣기)
```

### 서버를 끄고 싶어요

터미널에서 **Ctrl + C**

### 압축을 풀었더니 폴더 안에 폴더가 또 있어요

```
shinbong-lunch-bot-main/
└── shinbong-lunch-bot-main/     ← 진짜 프로젝트는 여기
    ├── app.py
    └── lunchbot/
```

**안쪽 폴더**를 밖으로 꺼내서 사용하세요.
`app.py` 가 바로 보이는 폴더가 맞는 폴더입니다.

### 카톡에서 받은 파일이 `neis(1).py` 로 저장돼요

같은 이름의 파일이 이미 있어서 그렇습니다.
**이름을 `neis.py` 로 바꾼 다음** 프로젝트 폴더에 덮어쓰세요.

이름이 다르면 프로그램이 그 파일을 찾지 못합니다.

### 덮어썼더니 내가 쓴 코드가 사라졌어요

남이 보낸 파일로 **내 담당 파일**을 덮어쓰면 내 코드가 지워집니다.

- 내 담당 파일은 남이 보낸 것으로 덮어쓰지 마세요
- Student D는 합치기 전에 폴더를 통째로 복사해 두세요
- 처음 상태로 돌아가려면 [GitHub](https://github.com/hyunjoon1012/shinbong-lunch-bot)에서 ZIP을 다시 받으면 됩니다

├── docs/
│   ├── architecture.md        전체 구조 설명

```

## 비밀번호와 API Key

API 키나 토큰이 생기면 **아무에게도 보내면 안 됩니다.** 비밀번호와 같습니다.

- 실제 값은 `.env` 파일에 넣습니다
- `.env` 파일은 **카톡으로 보내지 않습니다. 인터넷에도 올리지 않습니다**
- 다른 사람에게는 `.env.example` 만 보여줍니다 (여기엔 빈 칸만 있습니다)

> 💡 이번 프로젝트는 NEIS 인증키가 없어도 동작합니다.
> `.env` 파일을 아예 만들지 않아도 괜찮습니다.

## 이 프로젝트에서 가장 중요한 것

1. 각자 **자기 프로그램**을 갖는다
2. 각자의 프로그램은 **혼자서 테스트**할 수 있다
3. 다른 친구의 프로그램이 끝날 때까지 **기다리지 않는다**
4. 마지막에는 반드시 네 명의 코드를 **하나로 연결**한다
5. 모르는 것은 AI나 인터넷으로 배워도 되지만,
   **자기 코드가 어떻게 동작하는지는 설명할 수 있어야 한다**
